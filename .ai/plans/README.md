# Direktori Plans (`.ai/plans/`)

Folder ini digunakan untuk menyimpan seluruh rencana pengerjaan (roadmap, spesifikasi fitur, rancangan arsitektur, dan refactoring) project **NusaMarket**.

## Format Penamaan File Plan

Gunakan penamaan yang konsisten agar mudah dilacak, contoh:
- `001-setup-autentikasi.md`
- `002-manajemen-produk.md`
- `003-sistem-keranjang-dan-checkout.md`

## Template Singkat Plan

SETIAP plan disarankan memiliki struktur:
1. **Tujuan / Overview**
2. **Detail Perubahan / Komponen yang Dikerjakan**
3. **Langkah Implementasi (Step-by-Step)**
4. **Verifikasi & Pengujian**
